> Per `HO-FINISH v1.0 §6 T5` and `HO-FRONT v2.0 §5`. Evaluates and applies `next/dynamic` code-splitting where net route bundle delta is measurably negative after wrapper cost.

## 1. Targets & Measured Outcomes

### Target 1: `PositionsTable` in `ProfileArena.tsx` (SHIPPED)
- **Status:** **APPLIED & VERIFIED**.
- **Mechanism:** Lazy-loaded via `next/dynamic(() => import("./PositionsTable").then(m => m.PositionsTable), { ssr: true })` inside `ProfileArena.tsx`.
- **Measured Win:**
  - Profile route `/u/[pseudonym]` own raw: **241,926 B → 219,047 B = −22,879 B (−22.3 KiB)**.
  - Measured against a same-tree CONTROL build of `origin/main` @ `d502b45` with the split absent (verified `next/dynamic` count in `ProfileArena.tsx` = 0), run in the foreground with HEAD compared before and after — not against a stale committed baseline from an older tree.
  - **Shared bundle UNCHANGED: 993,244 B → 993,244 B, exactly 0 B.** The split moves nothing into the graph every other route pays for, so no other surface bears a cost.
- **Test Invariants:**
  - `tests/unit/profile/render/panel-filter.test.tsx` updated with `await screen.findByTestId(...)` (17/17 tests passing green).
  - Ratchet test in `tests/unit/scripts/bundle-baseline.test.ts` updated to allow `ProfileArena.tsx` as the single sanctioned dynamic site and lower the profile route ceiling to `230_020 B` (+5% of lowered base).

### Target 2: `DebateView.tsx` Probe (CLOSED — "Measured, and not worth doing")
- **Status:** **CLOSED AS NOT WORTH DOING** per §6 rule.
- **The number §6 asks for — net route-own delta after wrapper cost. Both directions UP:**
  - `DebateView` wrapped in `dynamic()` from the server page (`page.tsx`): `/m/[slug]` own **271.9 → 274.7 KiB (+2.8 KiB)**. No real split even occurred — the client-reference manifest still listed `async: false` with an identical chunk set.
  - A genuine client-side split (`ImageLightbox` wrapped from *inside* `DebateView.tsx`, a `"use client"` file) DID register in `react-loadable-manifest.json` and DID remove `ImageLightbox` from the route's `clientModules` — and the route's own bytes **still rose, 271.9 → 276.8 KiB (+4.9 KiB)**.
  - Both reverted; restoration md5-verified against HEAD.
- **Why it does not net out:** the `next/dynamic` loadable runtime costs more than the deferred component saves at this size. That is the same asymmetry target 1 exploits in the other direction — `PositionsTable` (1,519 lines) is large enough to pay for its wrapper; the lightbox is not.
- **Context, NOT the criterion:** `/m/[slug]`'s exclusive chunk total is 86.1 KiB raw / 24.3 KiB gzip across 3 chunks. That is the SIZE OF WHAT COULD BE SPLIT, not the net delta after wrapper cost. It does not answer §6 and is recorded only as background.
- Per HO-FINISH §6: *"If `DebateView` does not net out, close it with the number and do not ship the split. That is the instrument working."* Closed on the numbers above.
